# Sound effects

Put real recorded sounds here, one per role. Any missing role is simply silent.
Accepted: `.wav` or `.mp3`.

| file | plays on |
|---|---|
| `whoosh` | start of each new part of the video |
| `cut` | the other cuts inside a part (light) |
| `pop` | a text box popping in (titles, labels, price) |
| `click` | small chips and second lines |
| `impact` | the opening frame and the price slam |
| `riser` | the build-up just before the price |
| `transition` | the switch into the price screen |
